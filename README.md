# Getro Community Job Board Recreation

An independent, full-stack community job-board application inspired by the publicly observable workflows of Getro Community.

## Project status

Initial requirements audit is documented in [docs/REQUIREMENTS_AUDIT.md](docs/REQUIREMENTS_AUDIT.md). The repository is being built on the `feature/getro-community-recreation` branch.

## Principles

- Recreate user-facing workflows with original implementation and design assets.
- Use only authorized job data; mark seed data as demo content.
- Protect candidate information and enforce admin authorization server-side.
- Treat feature parity as unverified until reference interactions and acceptance tests pass.

## Planned capabilities

Job discovery and filtering, company directory, job details and apply links, candidate accounts and talent profiles, saved searches and email alerts, admin moderation, authorized data imports, SEO metadata, tests and deployment documentation.

See the requirements audit for the initial scope, recommended stack, routes, data model and acceptance criteria.
